# AGENTS.md

Instructions for all AI coding agents working in this repository.

- Keep code comments succinct: maximum 2 lines per comment.
- Prefer one line; use the second line only when needed for clarity.
- Never expand a comment beyond 2 lines; shorten or split the code instead.
- Write new C++ in C++23 style (CMAKE_CXX_STANDARD 23).
- Prefer constexpr std::array, ranges algorithms, and anonymous namespaces over C arrays, index loops, macros, and static.
